## HyperOS 深度优化脚本 Deep Optimization Script (Rootless)

### 由于HyperOS时代的MI严格控制引导程序解锁门槛，为了在等待期内体验清爽的HyperOS，特制作此脚本

### 优化详细说明后续更新

### 脚本命名规则(请选择对应平台的脚本进行操作)：batch_{操作类型}_{适用平台}.{平台通用后缀名}

### 确保你的platform-tools(adb组件)已经配置到系统或用户空间环境变量 此脚本需要打开设备端USB调试并提前关闭MIUI系统优化(系统优化在应用深度优化后也不应开启,且不建议关闭USB调试)

### 操作类型介绍：optimization(应用优化),restore(撤销所有修改)

##### 当前说明文档版本: V1.0
